# Was in die selbst gebaute libmpv-2.dll kommt (bauen.sh, Ablauf libmpv.yml).
# Jede Zeile: Name, Git-Quelle, Tag und der Commit, auf den der Tag zeigen
# muss. holen.sh holt genau diesen Commit und bricht ab, wenn der Tag
# inzwischen woanders hinzeigt — so steckt in der DLL nie etwas anderes als
# hier steht, und das Quellenarchiv enthält genau diese Bäume.
#
# Steht statt eines Tags ein „-", ist der Commit selbst die Fassung (die drei
# Bibliotheken unter shaderc: die Commits aus dessen DEPS-Datei).
# Untermodule (libplacebo: glad, jinja, markupsafe, fast_float,
# Vulkan-Headers) legt der Commit des Hauptpakets fest; holen.sh schreibt
# ihre Commits ins Verzeichnis (LIESMICH.txt im Quellenarchiv).
#

# annotierten Tags die Zeile mit ^{}), auf einem Arbeitszweig pushen —
# libmpv.yml baut und prüft. Danach die neue DLL pinnen (libmpv.txt).
