# Welche libmpv in den Installer von Lumen für Windows kommt (laden.sh)
# und welches Quellenarchiv dazugehört (tools/mpv_quellen.sh).
#
# Die DLL ist selbst gebaut: Ablauf libmpv.yml aus den festen Quellen in
# desktop/windows/mpv/bau/pakete.txt. Die Dateien liegen nie im Repository,
# sondern
#   TAG   an der eigenen Vorab-Veröffentlichung libmpv-JJJJMMTT (dauerhaft;
#         Pflicht für jede Lumen-Veröffentlichung), oder
#   LAUF  als Artefakt „libmpv" eines Laufs von libmpv.yml (90 Tage; nur
#         für Arbeitszweige, solange es noch keine Veröffentlichung gibt).
# Steht TAG, gilt TAG.
#
# SHA256 ist die Prüfsumme der libmpv-2.dll, QUELLEN_SHA256 die von
# libmpv-quellen.tar.xz — beides steht in der Zusammenfassung des Laufs.
#
# Neue libmpv: pakete.txt ändern, auf einem Arbeitszweig pushen (libmpv.yml
# baut), hier LAUF und die Prüfsummen eintragen und TAG leeren; die
# Windows-App prüft sie mit dem Selbsttest. Vor einer Lumen-Veröffentlichung
# libmpv.yml auf main mit „veroeffentlichen" und „lauf" = diesem LAUF
# starten: Das veröffentlicht genau die geprüfte DLL. Dann TAG eintragen und
# LAUF leeren; die Prüfsummen bleiben dieselben.
