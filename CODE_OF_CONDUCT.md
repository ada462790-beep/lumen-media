# Verhaltenskodex

*[English below](#code-of-conduct)*

Für Lumen gilt der
[Contributor Covenant, Fassung 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/)
([englisch](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)).
Kurz gesagt:

- **Respektvoll und freundlich** miteinander umgehen — in Issues,
  Pull-Requests, Kommentaren und überall sonst, wo das Projekt auftritt.
- **Sachlich bleiben:** Kritik gilt dem Code und den Ideen, nicht den
  Menschen. Unterschiedliche Erfahrung und Meinungen sind willkommen.
- **Nicht in Ordnung** sind Belästigung, Beleidigungen, sexualisierte
  Sprache, persönliche oder politische Angriffe, Drohungen und das
  Veröffentlichen privater Angaben anderer (etwa Name, Adresse, Server)
  ohne deren ausdrückliche Erlaubnis.

**Melden:** Wer etwas erlebt oder beobachtet, das gegen diesen Kodex
verstösst, meldet es den Betreuern des Projekts vertraulich über GitHub —
über die Funktion *Report content* beim jeweiligen Beitrag
(Menü „…" › *Report content*), die GitHub an die Betreuer weiterleitet.
Betrifft es Sicherheitslücken, gilt [SECURITY.md](SECURITY.md). Meldungen
werden vertraulich behandelt.

Die Betreuer können Beiträge bearbeiten oder entfernen und Personen
verwarnen, vorübergehend oder dauerhaft ausschliessen — nach den
Richtlinien zur Durchsetzung des Contributor Covenant 2.1.

# Code of Conduct

Lumen follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful and constructive; harassment, insults, sexualized language,
personal or political attacks, threats and publishing others' private
information without permission are not acceptable.

To report a violation, use GitHub's *Report content* feature on the
comment, issue or pull request in question (menu "…" › *Report content*);
for security vulnerabilities see [SECURITY.md](SECURITY.md). Reports are
handled confidentially. Maintainers may edit or remove contributions and
warn, temporarily or permanently ban participants, following the
Contributor Covenant 2.1 enforcement guidelines.
